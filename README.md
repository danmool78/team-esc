# 비전현장미션 — 팀 미션

팀원들과 실제로 걸으며 미션을 푸는 웹 앱. 모두의 위치가 실제 3D 지형 위에 미니미 인형으로 보이고, 상대 팀의 미션 수행 수가 실시간으로 올라갑니다.
배포: https://team-esc.web.app · 데모: https://team-esc.web.app/?demo

- **가입**: 구글 계정 또는 이메일. 처음 한 번 별칭을 정하고, 남/여를 고르면 미니미 옷차림이 무작위로 정해집니다.
- **게임**: 진행자가 지역(기본 전주 한옥마을)과 팀을 정해 게임을 만들고, 참가자는 5자리 코드로 들어옵니다.
- **지도**: 3D 위성 지형 위에 참가자 인형과 미션 빛기둥. 별칭이나 팀 이름으로 검색하면 그 자리로 이동해 따라갑니다.
- **미션**: 도착 · 퀴즈 · 사진 · 현장 미션. 진행자는 게임 중에도 미션을 더하고, 사진·현장 미션을 확인해 점수를 줍니다.

빌드 도구 없는 정적 사이트입니다. 로컬 실행: `python -m http.server 8765` 후 http://localhost:8765/?demo
